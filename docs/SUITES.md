## 分档压测

默认的“流式并发压测 · 截图报告”直接加载 `llm-benchmark/benchmark.py`，报告保留原有 25 项指标、延迟分位数、曲线、逐请求明细和 PDF 打印、CSV、JSON 导出。报告嵌入受限 iframe，也可打开完整 HTML。

支持指定并发档位或起始 / 结束 / 步长。范围结束值会包含在计划里，即使不能被步长整除。每个档位独立归档，不把所有阶段混算成一个结论。

工作台复用旧版报告绘图代码：左侧为记录，右侧为完整指标、延迟分位数、TTFT / TPOT / 总延迟曲线与请求明细。报告按内容高度展开，运行时更新数据而不重载图表页面。曲线支持图例开关和悬停数值，CSV / JSON 导出及 PDF 打印仍可使用。压测执行后自动进入工作台；批次运行时跟随当前阶段，手动选择记录后停止跟随。原管理入口收在左侧“管理”菜单。

新增只读 API：`GET /api/suites/runs/{id}/benchmark` 提供运行中的指标与最近最多 500 条请求样本，结束后提供完整已归档报告；`GET /api/suites/runs/{id}/view` 提供隔离展示页。页面通过受限消息通道接收更新和报告高度，下载的原始 HTML / JSON 不会因此改写。

建议首次测试用户指定的 `deepseek-v4.1-flash`：

| 参数 | 初始值 |
| --- | --- |
| 渠道基础地址 | `https://tokenhub.tencentmaas.com/v1` |
| 模型 | 在该渠道登记的 `deepseek-v4.1-flash` |
| 并发档位 | `1,5,10,20,50` |
| 每档请求数 | 20 |
| 输入 Token 目标 | 1000 |
| 最大输出 Token | 256 |
| 单请求超时 | 120 秒 |
| 发起窗口 | 0，即按请求数停止发起 |
| 总计划超时 | 3600 秒 |
| 每组重复 | 1 |

以上为 5 阶段、最多 100 次请求；输入目标加输出上限合计 125600 Token，不是官方账单估计，也不证明渠道能承受该并发。先用单并发 1 次验证连通，再逐步加压。客户端并发范围为 1～500，真实限额由渠道决定。

逐变量模式使用其余轴首档为基线，去掉重复基线。例如并发 5 档、输入 3 档、输出 2 档，共 8 阶段；笛卡尔积为 30 阶段。重复次数会再乘入预算。单计划最多 64 阶段、累计 100000 次请求上限；一次只运行一个新套件任务。时间窗口或取消可能使实际发送数低于上限。不同总时长的阶段应分别分析。

TTFT 取首个正文或 reasoning 片段；TPOT 取首末生成片段间隔 / (输出 Token - 1)；TPM 是全程速率折算，百分位为线性插值。生成输入用 cl100k_base 本地目标，实际输入、输出、缓存和吞吐以供应商 Usage 为准。缺失值保持为空。缓存 Token 属于输入子集，总 Token 不重复加缓存。

## 旧脚本

适配了通用入口的 18 类测试，以及纯文本峰值 TPM、独立验收包、渠道 AZ 诊断；参数由 `backend/app/suites.py` 白名单生成，使用当前平台解释器。外部脚本按自己的轮数 / 请求参数运行，截图压测另外支持输入、输出、并发的跨轴批次。

所有新套件执行使用 argv、`shell=False`，Key 只通过 `MT_SUITE_API_KEY` 环境变量注入；原脚本继续独立可用。将 `--output-dir` 或 `TEST_RESULT_ROOT` 指向平台归档目录。视频 / 混合媒体套件需要明确选择已有本地素材；素材路径与 SHA256 进入预览。独立验收包继续使用其配置及 fixtures，不自动生成或下载媒体。

纯文本峰值套件使用完整滚动 60 秒完成窗口、正文首字和原始成功断言；输入单位为重复文本单元。默认值从脚本读取，目前 128 RPS × 120 秒 + 1 次探测，640 并发、32768 输入单元、请求硬上限 16000。与截图压测的全程折算口径分开存储，须在计划中核对请求规模。

每次运行保存来源、源码哈希、目标端点、模型、配置、阶段、退出码、原始 summary JSON / CSV、日志和文件哈希。日志限制约 10MB，并保留最近 300 段。运行可取消；总任务超时会终止脚本及子进程。部分 macOS 环境不允许进程组信号时，会使用读取到的子进程 PID 清理。服务正常退出会取消活动任务，重启后把遗留套件记录标记为中断，不自动重跑。

“执行完成”只表示引擎或脚本结束，`passed` 保持 false；原始业务结论仍在源报告里。CSV 的 result / HTTP 状态只按原字段计数，不由退出码推断通过。这些记录不自动写入兼容性矩阵，模拟记录也不会成为真实兼容性结论。

## 历史与边界

“测试报告 → 历史压测报告”可导入 `llm-benchmark/results/*/report.json` 配套报告。先只读识别，点击后复制到平台独立归档；来源路径及 SHA256 相同的报告重复导入不增加记录，原文件不修改，保留原状态和配置。历史导入时间是平台归档时间，原始执行时间见 report JSON / HTML。

本版没有批量转换所有旧 XLSX / HTML 或自动覆盖全部 35 项能力。K3 旧验收、GLM / Qwen 专属脚本、客户标准、素材、表格及平台模板已在基线和来源目录中记录，未适配项明确标注为资料索引。Anthropic、Batch、FIM、联网等需要相应专属适配，不能以普通 Chat 成功代替。平台运行期间不要独立启动同渠道压测来合并统计。

## 单项与全部执行

测试套件的执行范围只显示“单个项目”和“所有项目”。选择单个项目时，下方出现“选择测试项目”下拉框及对应参数；选择所有项目时，显示全部已适配的 24 项清单，可点击项目旁的配置按钮调整参数。“一键测试全部项目”同样预览这 24 项，确认后执行。其中 18 项通用项目按本机总脚本顺序排列，另六项为截图压测、纯文本峰值、独立验收、AZ 探测、统一 API 矩阵与 RPM / 缓存指标；未适配的资料索引不混入执行范围。API 保留指定批次能力供脚本调用。

通用项目默认参数按本机总脚本校准；未显式覆盖的参数从对应 Python `argparse` 的字面量默认值读取，不导入执行测试脚本。完整历史对话默认 100 轮、最大输出 512；TPM 为 292 请求 / 80 并发 / 35000 输入 / 96 秒；流式指标 90 请求；延迟每组合 10 请求。大请求体展开为 50、70、80、90、95、100 MB 六档，因此 18 项为 23 个独立执行阶段。各项目设置和截图压测档位在本机浏览器中分别保留，可恢复默认值。

批量 API 复用 `/api/suites/preview` 与 `/execute`，请求增加 `suite_ids`、`suite_parameters`、`continue_on_error` 和 `cooldown_seconds`。每个项目保留独立参数、脚本哈希、素材哈希、运行记录与证据目录；所有项目预检成功后才能执行，不静默跳过缺失素材。预览后脚本或素材变化会阻止对应阶段。默认项目异常后继续其余项目，可改为停止；TPM、流式指标之后按总入口安排冷却，默认 70 秒，可调整。取消和整个计划超时会停止当前请求及未开始阶段。

每个计划最多 128 阶段，已知计划请求合计最多 100000；预算不明确的脚本单独标注由用例决定，不填成 0。不明确的预算不构成费用上限。整个计划默认超时 86400 秒。单项目 API 与既有工作台仍兼容。

## 可编辑与版本报告

单个计划结束后自动生成汇总报告；历史运行可点击“自定义报告”，整个任务可点击“任务汇总报告”。可编辑报告与原始运行报告在报告页分开展示。

支持报告标题、副标题、结论、标准 / 紧凑 / 验收版式、主题色、章节和结果表栏目。结果行可修改、隐藏、新增、上下移动、恢复原始值，支持筛选与分页。右侧实时 HTML 预览；修改草稿保存在当前浏览器，保存后可重新打开和查看历史版本。每个保存版本记录编辑人、修改说明、时间，并检查基础版本以防覆盖并行编辑。

报告的原始快照与编辑版本分别存入 `suite_reports`、`suite_report_versions`。源脚本明确的 PASS / FAIL / SKIP 按原断言展示；HTTP 200、退出码 0 和成功率不推断为业务验收通过。人工修改与新增行在 HTML 中标记绿色左线，原始运行文件及清单不改写。原始证据章节保留脚本和清单 SHA256；JSON 导出同时包含报告内容与原始快照。

支持导出已保存版本的独立 HTML、CSV（Excel 可打开）、JSON，文件名包含时间、渠道、模型和版本。可编辑报告最多汇总 1900 行，每张源 CSV 收集前 100 行；完整逐请求记录从运行证据下载。截图压测曲线每运行保留前 500 个样本，TTFT / TPOT / 端到端延迟分别绘制；无压测样本时说明无曲线，不生成假数据。完整旧版交互曲线和 25 项指标仍在原始压测报告中。

API 前缀 `/api/suite-reports`：`GET /` 列表、`POST /` 按 `job_id` 或 `run_ids` 幂等生成、`GET /{id}?version=N` 查看、`POST /{id}/versions` 保存新版本、`POST /{id}/preview` 在线预览、`GET /{id}/export/{html|csv|json}?version=N` 导出。预览和 HTML 均转义用户文本并限制沙箱，CSV 防止文本作为公式执行。
